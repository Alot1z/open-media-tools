# open-media-tools

Open-source browser-native media downloader / tool platform.

**Status:** Planning (Pass 1 / Pass 2 / Pass 3 in progress).

## Goals

- Public GitHub repository, GitHub Pages production website
- Browser/local execution wherever technically possible
- Minimal remote infrastructure, with remote fallback where browser execution cannot realistically work
- GitHub Actions for CI/CD / release / maintenance / deployment (NOT runtime for normal user downloads)
- Extensible media/platform architecture
- Desktop + mobile, strong Safari/iOS support, Chromium + Firefox support

## Initial target platforms

TikTok, Instagram, Facebook — architecture must NOT be hard-coded around those.
